# Image-surface experiment

This is an isolated staging-only PixiJS/WebGL experiment, enabled with `?experiment=surface`. It is not registered in the recommendation catalog. It accepts the selected image and the existing clip-relative `ReactiveTimeline`; lyrics remain a separate, unfiltered text layer using the existing composition cue evaluation. The original image and song remain on the user's device. Preview and MP4 export call the same explicit-frame scene and fixed seed.

`visual-signals/adapter.ts` turns actual beat positions, onset times and RMS energy into bounded beat, transient and energy values without using BPM or unverified downbeats. RMS is normalized to the clip's 90th-percentile level with a floor. Beat/transient envelopes have bounded recovery, weighted by local RMS. Music Analysis v1 does not supply isolated low-frequency energy; beat plus RMS is only an intensity proxy, not bass detection. A real silent analysis stays silent. If analysis is absent, fixed deterministic test events are labeled as fallback, not music detection.

The surface applies a low-amplitude centered crop, slow ambient drift, energy-weighted pressure, a local shader deformation and a short chromatic offset only for stronger onset envelopes. The experimental parameters are `intensity`, `displacementStrength`, `ambientMotion`, `transientResponse` (each 0–1), and `recoveryMs` (80–1600 ms). These are bounded in the scene and are not customer controls. No new dependencies or third-party media were added.

On the existing hardware-accelerated Intel Mac, a local 450-frame 1080×1920 H.264/AAC test using original bundled artwork and synthetic events completed in 3.52 seconds; mean sampled preview/export RGB difference was 2.96/255. This is a single controlled measurement, not a performance guarantee. Actual song analysis is limited by the existing separate staging music-worker credential; the staging experiment clearly identifies when fallback is active. Subject-aware cropping, musical low-frequency extraction and broader browser/GPU benchmarking are not implemented.
