# CLAP genre research

This is an isolated, staging-only research tool. It uses the Apache-2.0 LAION music checkpoint revision a0b4534a14f58e20944452dff00a22a06ce629d1. The checkpoint SHA-256 is verified before loading. To build the image, the approved checkpoint snapshot must be present at the path defined in worker.py. Weights and private audio are never committed.

The browser decodes the original locally and uploads exactly 15 seconds of mono 16 kHz PCM WAV. The worker validates the exact size and header, resamples in memory, and runs two fixed 10-second windows at 0–10 and 5–15 seconds. It writes no audio files. Similarities are cosine scores. The combined ranking is the arithmetic mean of both windows, not a confidence value. Candidate text is fixed as prompt version 1. Window disagreement and all raw scores remain visible.

Access codes are expiry and HMAC signatures scoped to mumoo-genre-research, with a separate rate counter. The shared secret is stored in the existing Modal staging secret. The gateway validates access before dispatch, caps uploads, and allows three analyses per minute and 30 per day. Netlify adds a per-IP limit. Worker and gateway scale to zero. No browser results or music are stored by the application. Scores, model results, and audio are not logged.

Initial synthetic-only hosted validation on 2026-11-04 returned cold 18.18 s and warm 3.44 s end to end. Model processing took 5.208 s cold and 0.884 s warm. Peak process RSS was 1,736,232,960 bytes. The synthetic clip is not evidence of genre accuracy.

Diagnostic mode is opt-in and returns two normalized audio embeddings, the complete scores, levels, model provenance, and preprocessing information to the requesting browser. The browser creates a random identifier and SHA-256 of the encoded 15-second WAV and offers a local JSON download. No audio samples, lyrics, filename or access code are included in that export. Errors are represented by a generic status. These diagnostic results and clips are not stored by the application or written to its logs. Embeddings and hashes are derived from audio and should be shared deliberately.

The research worker now marks clips below an RMS level of 0.001 in normalized full scale (approximately -60 dBFS) as unavailable before classification. This is a conservative engineering threshold for this experiment, not a validated detector of music or genre.

Baseline prompt version 1 is unchanged. On the generated pulse, silence and sine controls before this guard, reggaeton and Brazilian funk automotivo ranked first for all three. Pulse/silence and pulse/tone embedding cosine similarity were 0.9982 and 0.9451. The earlier independent forward-pass check agreed within 0.00000004, and text embedding order was verified. These controls do not establish model accuracy on real music. Audio is reduced to 16 kHz before resampling to the model's 48 kHz input. Frequencies above 8 kHz are therefore lost, a potential source of degraded performance that requires a controlled comparison with higher-rate input.

The optional 48 kHz comparison makes two independent mono 15-second PCM versions from the same original browser source. The baseline retains the existing browser 16 kHz extraction followed by SciPy 3:1 resampling. The direct path decodes the original source in a 48 kHz AudioContext and renders at 48 kHz. Both paths retain the same fixed model, prompts, windows, scoring, and silence guard. Original recordings with a lower native sample rate cannot gain missing high-frequency detail.

The authenticated comparison request concatenates a 480,044-byte 16 kHz WAV and a 1,440,044-byte 48 kHz WAV. Both headers and lengths are independently validated. The report includes scores, embeddings, RMS, peak, 8–24 kHz spectral-power fraction, processing time and peak process RSS for both paths. The power statistic is based on an unwindowed full-clip FFT and is a coarse diagnostic, not a calibrated measurement.

Initial generated controls withheld silence on both paths. A 440 Hz tone and a synthesized percussion pattern retained the same top three broad genres and subgenres on both paths. These controls do not establish whether higher-rate source music improves genre discrimination.
